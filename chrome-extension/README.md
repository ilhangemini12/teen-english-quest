# BatumHub Chrome Extension

Manifest V3 extension for quick access to BatumHub.

## Current features

- Choose English, Spanish, German or Russian.
- Keep a CEFR level preference (A1-C1).
- Quick-open BatumHub, Learn or Vocabulary.
- Right-click selected text on any webpage and send it to BatumHub.
- Uses only Chrome storage, contextMenus and tabs permissions.
- No remote code and no access to page contents beyond text the user explicitly selects.

## Load locally

1. Open `chrome://extensions`.
2. Turn on **Developer mode**.
3. Choose **Load unpacked**.
4. Select the `chrome-extension` folder.

Before Chrome Web Store submission, add PNG extension icons (16/32/48/128), screenshots, privacy disclosure and store metadata.
